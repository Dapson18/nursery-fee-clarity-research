# Nursery Fee Clarity — public research preview

An early-stage, **fictional** interactive demonstration of evidence-linked childcare-fee explanations. This repository hosts only a static research site: no production fee-verification engine, private model output, API keys, family documents or personal data.

## Website

- `site/index.html`: interactive demonstration and copy-only research questionnaire.
- `site/privacy.html`: privacy and research limitations.

All example prices, booking rules and charges are invented. No live nursery quotes, real funding/entitlement decisions, document submissions, or fee-verification API is offered.

**Research feedback is not submitted or saved on the server.** The visitor can copy it locally and share it separately; no email or survey destination is configured yet.

## Deployment

Use a separate Render Static Site, branch `main`, build command `echo research-preview`, publish directory `site`. Other services remain independent.

## Evidence status

The first unseen-provider evaluation gave 4 matching numerical answers out of 12 cases, with eight withheld. Methodological differentiation is under investigation, not proven competitive superiority or endorsement.
